# Ejercicios 9 al 12

Este directorio contiene los ejercicios 9 al 12 de programación básica, cada uno resuelto en un script de Python independiente.

## Ejercicio 9: Serie de Fibonacci
- **Archivo:** `fibonacci.py`
- **Descripción:** Genera un vector (lista) de números de Fibonacci a partir de dos valores iniciales y una longitud dada. Imprime la serie resultante.
- **Ejecución:**
  ```bash
  python fibonacci.py
  ```

## Ejercicio 10: Ordenar Fibonacci en forma decreciente
- **Archivo:** `fibonacci_ordenado.py`
- **Descripción:** Genera la serie de Fibonacci como en el ejercicio anterior y luego la imprime ordenada de mayor a menor.
- **Ejecución:**
  ```bash
  python fibonacci_ordenado.py
  ```

## Ejercicio 11: Comprobar si un número pertenece a la serie de Fibonacci
- **Archivo:** `fibonacci_comprobar.py`
- **Descripción:** Comprueba si un número entero positivo pertenece a la serie de Fibonacci usando la fórmula de Binet.
- **Ejecución:**
  ```bash
  python fibonacci_comprobar.py
  ```

## Ejercicio 12: Suma recursiva de cuadrados
- **Archivo:** `suma_cuadrados_recursiva.py`
- **Descripción:** Calcula recursivamente la suma de los cuadrados de todos los números entre un límite inferior y superior (inclusive).
- **Ejecución:**
  ```bash
  python suma_cuadrados_recursiva.py
  ```

---

Cada script es interactivo y solicita los datos necesarios por consola.
