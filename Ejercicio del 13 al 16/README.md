# Ejercicios de Programación 13-16

Este directorio contiene la solución a cuatro ejercicios de programación en Python.

## Ejercicio 13: Conversor de Bases Numéricas

Programa que permite:
- Introducir un número entero en cualquier base (binario, octal, decimal o hexadecimal)
- Validar las entradas para asegurar que son correctas
- Convertir el número a una base diferente según lo solicite el usuario
- Mostrar el resultado de la conversión

## Ejercicio 14: Números a Palabras en Inglés

Programa que:
- Acepta números enteros de hasta cinco dígitos
- Convierte el número a su representación en palabras en inglés
- Ejemplos:
  - 65 → Sixty Five
  - 12345 → Twelve Thousand Three Hundred and Forty Five

## Ejercicio 15: Calculador de Día de la Semana

Programa que:
- Acepta cualquier fecha del siglo 21 (2000-2099)
- Valida la entrada verificando:
  - Número de días en cada mes
  - Años bisiestos
  - Número de meses en un año
- Muestra el día de la semana correspondiente a la fecha ingresada

## Ejercicio 16: Calculadora de Paralelepípedo

Programa sencillo que:
- Solicita las dimensiones de un paralelepípedo (largo, ancho y alto)
- Calcula y muestra:
  - El área total del paralelepípedo
  - El volumen del paralelepípedo

## Uso

Cada ejercicio está contenido en su propio archivo Python (.py). Para ejecutar cualquiera de los programas:

1. Asegúrese de tener Python instalado en su sistema
2. Abra una terminal en este directorio
3. Ejecute el programa deseado con el comando:
   ```
   python ejercicioXX.py
   ```
   (donde XX es el número del ejercicio: 13, 14, 15 o 16)

## Notas

- Todos los programas incluyen validación de entrada para evitar errores
- Los programas son interactivos y permiten realizar múltiples cálculos/conversiones
- Se incluyen mensajes de error claros cuando la entrada no es válida
